
## Project Description

### This issue addresses the main issue: Finding sports places near town.

For example if an online user looks up online:
'basketballplatz konstanz' not many results are found and also in a bad quality. <br>
My app focuses on: 

- SEO optimized results: <br>
 ('tischtennis platte konstanz =  <br>
 '5 Ergebnisse in -Konstanz- gefunden, *Ergebnisse anklicken*')
- qualitative results (with pictures, details, ratings, comment section)
- community driven (a user can anonymously tick on a calendary, to show that he/she will be there at monday 5 p.m. f.e.)
- future features such as 'events' where strangers can meet in an event at a sportsfield

## Local Installation on Windows

- install nodejs, pnpm, postgres
```bash
pnpm i      -> installs all configurations in package.json (f.e.: tailwind, next, react, ..)
```
- for Postgres in Windows Subsystem Linux go to /docs/Postgres-in-WSL-README
- read the Prisma section first

## Getting Started

First, run the development server (read first the prisma section):

```bash
pnpm run dev    -> starts the development server using Turbopack (default bundler)
```

```bash
next dev    
pnpm run build  -> builds the application for production
pnpm start      -> starts the production server
pnpm eslint     -> runs ESLint
```

## Prisma = Database abstraction layer for Postgres

The Prisma model is created/generated by 'db pull', which is basically the PostgreSQL schemas 
translated into prisma models (ORM). <br> Run db pull if the PostgreSQL tables changed, 
then run prisma generate. Also run prisma generate after git clone.
```bash
$env:DATABASE_URL = 'postgresql://postgres:passwort123@localhost:5432/sportplaetzeDB'
pnpm prisma db pull
pnpm prisma generate
```


Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
